# NEXUS-09 // NEON ESCAPE

### Introduction

Nexus-09 is a cyberpunk escape game where the player needs to recover all four access fragments,bypass system security, and escape a failing machine intelligence before the containment lock seals the partition.

### Tech Stack
- HTML
- CSS
- JavaScript

### Features

- Neon cyberpunk visual design and glitch-style UI
- A 5 minute countdown challenge with escalating pressure
- Four distinct puzzle rooms:
  - Security terminal code challenge
  - Signal sequence memory test
  - Memory lattice matching game
  - Reactor core alignment puzzle
- Progress tracking with fragment collection and HUD updates
- Animated particle background and scanline effects
- Audio tones for clicks, errors, success states, and completion cues
- Score calculation and performance ranking system
- Best run persistence using browser localStorage
- Responsive browser gameplay with no external libraries or build tooling

### How to Play

1. Click the Initialize Escape button on the start screen.
2. Solve the terminal puzzle to obtain Fragment 01.
3. Move through the signal, memory, and core challenges.
4. Unlock the core once the required fragments are secured.
5. Collect all four fragments.
6. Trigger the final escape sequence before the partition locks you out.
7. Review your final score and try again for a better rank.
